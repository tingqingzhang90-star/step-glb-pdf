# 自研工程图编辑器方案

> 面向 `cad-viewer-app` 的自研工程图实现方案

## 1. 目标

本方案不再依赖 SolidWorks `.SLDDRW` 标注提取作为主线，而是直接实现一套自研工程图编辑器，用于：

- 自动生成标准视图
- 在图纸上拖拽、摆放、缩放视图
- 手工添加线性、直径、半径、角度标注
- 支持文字、中心线、标题栏、表格
- 模型系列变化后自动更新视图
- 标注尽量保持语义关联，不随视图漂移

## 2. 需求拆分

### 2.1 短期

先做可用的工程图 MVP：

- 导入模型
- 自动生成视图调色板
- 拖拽视图到图纸
- 调整视图位置与比例
- 添加基础标注
- 保存工程图文档

### 2.2 中期

建立关联更新能力：

- 模型更新后重建视图
- 标注绑定语义锚点
- 用几何指纹重新匹配边、面、孔、轴
- 旧标注自动重绑定

### 2.3 后期

形成系列模板能力，并完善 SolidWorks 式的派生视图交互：

- 250 系列共用模板
- 不同安装方式、负载连接、系列差异只切模板参数
- 自动套用标题栏、视图布局、默认标注
- 从当前视图沿上下左右方向拖动，实时预览并创建派生视图
- 支持以任意当前视图作为新的正视基准继续派生视图
- 派生视图保持父子关系、投影方向和对齐关系

## 3. 核心原则

1. 视图只负责显示，不负责标注求值。
2. 标注不绑定屏幕坐标，绑定语义锚点与几何指纹。
3. 同系列产品优先复用模板，不依赖外部工程图反向提取。
4. 标注失配时提示用户修复，不做静默错误映射。

## 4. 数据结构

### 4.1 DrawingTemplate

描述某一系列图纸的布局规则、默认视图、默认标注和适用条件。

```json
{
  "template_id": "250-E-H3K2",
  "name": "250系列液压缸模板",
  "sheet": {
    "size": "A3",
    "width": 420,
    "height": 297
  },
  "apply_rules": {
    "series": "250",
    "mount": "H3K2"
  },
  "views": [],
  "annotations": [],
  "title_block": {}
}
```

### 4.2 DrawingDocument

描述当前用户正在编辑的工程图实例。

```json
{
  "document_id": "doc_001",
  "template_id": "250-E-H3K2",
  "model_id": "250-E-H3K2-L100-D11",
  "sheet": {},
  "views": [],
  "annotations": [],
  "revision": 1
}
```

### 4.3 ViewInstance

描述图纸上一个视图实例。

```json
{
  "id": "front",
  "source_view": "front",
  "projection": "front",
  "x": 80,
  "y": 180,
  "scale": 1.0,
  "bbox": {
    "width": 180,
    "height": 120
  },
  "geometry": {
    "visible_edges": [],
    "hidden_edges": []
  }
}
```

### 4.4 AnnotationBinding

描述标注如何绑定到模型几何或语义锚点。

```json
{
  "id": "dim_total_length",
  "type": "linear",
  "view_id": "front",
  "value": 320,
  "binding": {
    "from_anchor": "cylinder.front_end",
    "to_anchor": "cylinder.back_end",
    "geometry_fingerprint": {}
  },
  "presentation": {
    "offset": 30,
    "text_pos": [120, 240]
  }
}
```

## 7. 开源 CAD Viewer 复用策略

`cad-viewer-app` 当前已经引入：

- `@mlightcad/cad-simple-viewer`
- `@mlightcad/cad-viewer`
- `@mlightcad/data-model`

这些开源包可以用于复用前端 CAD 交互能力，但不作为自研工程图的数据主线。

### 7.1 可以复用的能力

优先复用以下前端交互和 UI 能力：

- 选择集与对象选中
- 鼠标拾取、框选、hover
- 缩放、平移、适应窗口
- 图层、颜色、线宽、线型 UI
- 属性面板 UI
- undo / redo 交互框架
- 测量 overlay 元素
- 捕捉提示和预览点

### 7.2 不作为主线复用的能力

不直接把 mlightcad 的 DXF/DWG 数据模型作为工程图主数据结构。

原因：

- 我们的工程图需要绑定 3D 模型语义锚点
- 标注需要随参数模型更新重绑定
- DXF/DWG 实体更偏向 2D CAD 图元，不天然表达 3D 参数模型关联

因此工程图主数据仍使用自研的 `DrawingDocument`、`ViewInstance`、`AnnotationBinding`。

### 7.3 推荐集成方式

采用“外壳复用，核心自研”的方式：

```text
mlightcad 负责：
  - 选择
  - 捕捉提示
  - 缩放/平移
  - 属性面板
  - 测量 overlay
  - 部分 CAD UI 组件

自研系统负责：
  - DrawingDocument
  - ViewInstance
  - AnnotationBinding
  - 语义锚点
  - 几何指纹
  - 模型更新后的标注重绑定
```

### 7.4 接入顺序

1. 先保留当前 SVG 画布和 HLR 视图渲染。
2. 调研并接入 mlightcad 的选择集、缩放、平移能力。
3. 将测量 overlay 用于标注创建过程的临时预览。
4. 标注完成后写入自研 `DrawingDocument.annotations`。
5. 不把最终工程图保存成 mlightcad 数据模型，仍保存为自研 JSON。

## 8. 后期完善：拖动派生视图

### 8.1 交互目标

用户选中一个已有视图后，沿当前视图的屏幕方向拖动：

- 向上或向下拖动：创建对应的正交派生视图
- 向左或向右拖动：创建对应的正交派生视图
- 向斜向拖动：可进入轴测或其他非正交视图预览
- 拖动过程中显示虚线投影关系、对齐线和派生视图预览
- 松开鼠标后固化视图实例，并建立父子视图关系

这里的方向必须相对于当前视图的局部坐标系解释，而不是固定使用模型世界坐标。例如，以左视图作为当前基准时，向下拖动应生成“以左视图为正视基准”的下方派生视图。

### 8.2 数据模型

视图实例需要增加派生关系和局部坐标信息：

```json
{
  "id": "derived_view_001",
  "parent_view_id": "left",
  "projection_mode": "orthographic_derived",
  "projection_direction": [0, -1, 0],
  "basis": {
    "right": [1, 0, 0],
    "up": [0, 0, 1],
    "view": [0, -1, 0]
  },
  "placement": {
    "x": 180,
    "y": 160,
    "alignment": "vertical"
  },
  "preview_status": "ready"
}
```

### 8.3 实时性设计

拖动阶段不重复执行完整 HLR 或后端投影。采用两层处理：

- 交互预览层：复用已缓存的视图几何，只更新局部坐标、位置、比例、对齐线和 ghost 视图
- 正式计算层：松开鼠标后异步生成最终投影几何，完成后替换预览数据

模型首次载入或模型参数发生变化时，才执行正式视图计算；普通拖动只处理布局和视图关系。

### 8.4 视图关系

工程图视图由 `ViewGraph` 管理：

- 节点是 `ViewInstance`
- 边是父视图到派生视图的投影关系
- 每个节点保存局部 `right / up / view` 基向量
- 子视图继承父视图的投影基准，并根据拖动方向生成新的投影方向
- 父视图移动、缩放或更新时，子视图可以按对齐约束同步调整

### 8.5 实施约束

- 派生视图预览不能阻塞鼠标拖动
- 预览失败时保留父视图，不创建错误的正式视图
- 正式计算失败时保留上一次有效几何，并显示待更新状态
- 标注绑定使用语义锚点和几何指纹，不绑定预览阶段的屏幕坐标
- 该能力属于后期完善项，不作为当前 MVP 的阻塞条件

## 9. 实施顺序

1. 固化工程图 JSON 数据结构
2. 在 `cad-viewer-app` 中拆分工程图编辑器组件
3. 接入模型视图生成与图纸画布
4. 复用 mlightcad 的选择、缩放、平移、测量 overlay 能力
5. 接入标注创建与保存
6. 接入锚点绑定与重绑定
7. 支持系列模板复用
8. 实现 `ViewGraph` 和父子视图关系
9. 实现基于当前视图局部坐标的拖动派生视图
10. 实现 ghost 预览、对齐线和后台正式重算

## 10. 近期决策

- `.SLDDRW` 标注提取停止投入
- 仅保留模板参考样本
- 主线全部转向自研工程图编辑器
