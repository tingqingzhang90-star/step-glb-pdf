# 工程图布局与断裂视图

长行程液压缸换型号出图时，缸体沿 Z 轴伸长，沿用基准型号的视图摆位会越出图框。现在主链路在出图前统一求解视图比例和间距，比例低到影响观看时改用 CAD 常见的断裂视图：缸体平直段中部省掉一截，用双波浪折断线表示，标注数值仍是实测毫米。

## 覆盖范围

接入的是前端实例模板这条主链路：`batch_drawing.generate_one_frontend()` → `dim_pdf_sheet` PDF + `drawing_source.json` → 前端 SVG / `drawing_source_render` PDF。旧规则式模板链路（`drawing_template.py` / `drawing_pdf.py`，绝对坐标加另一套 `shared_auto_scale`）没有改造，仍然参与默认 CLI、Web 调试接口和 DXF 导出；它不产出 `view.break`，因此不会显示断裂视图。

`sw_view.py` 的 `motor_envelope` / `gearbox_envelope` 继续返回模型毫米真值。断裂投影放在消费端（前端 `getSheetPoint`、后端 `dim_render._sheet_point`），避免把端面真值改短后又被重绑当作错误数据。

## 配置项

配置读法沿用 `drawing_engine`：`os.environ` 优先，项目根 `.env` 兜底，都有默认值。`.env` 是本地文件，不入库；默认值以 `src/drawing/sheet_layout.py` 的 `_CFG_DEFAULTS` 和下表为准。

| 键 | 默认值 | 作用 |
|---|---|---|
| `DRAWING_SHEET_MARGIN` | 20 | 图框内边距，mm；与前端 SVG、两套 PDF 图框统一 |
| `DRAWING_SHEET_TITLE_BLOCK_MM` | 55 | 底部标题栏占位高度，mm |
| `DRAWING_VIEW_MIN_GAP_MM` | 12 | 视图之间最小间距，mm |
| `DRAWING_VIEW_ALIGN_TOL_MM` | 20 | 按模板 x/y 聚类同行同列的容差，mm |
| `DRAWING_MIN_READABLE_SCALE` | 0.75 | 统一缩放低于此值时启用断裂 |
| `DRAWING_MAX_VIEW_SCALE` | 2.0 | 统一缩放上限 |
| `DRAWING_BREAK_OMIT_MM` | 400 | 断裂至少省略的模型长度，mm |
| `DRAWING_BREAK_WAVE_AMP` | 3 | 波浪线振幅，画布 px |
| `DRAWING_BREAK_WAVE_CYCLES` | 3 | 波浪数 |
| `DRAWING_BREAK_VISUAL_GAP` | 6 | 两切口之间保留的视觉间隙，画布 px |

`DRAWING_MIN_READABLE_SCALE` 同时是软开关：设到 `0.01` 就只做缩放适配，永不生成断裂。省略量不是固定值——先算「把比例拉回阈值所需」的画布长度，再和配置的最小省略长度取大，最后受内容宽度约束。

## 布局求解

`src/drawing/sheet_layout.py:solve_layout()` 输入图纸尺寸和各视图的 `contentBBox`（400×300 调色板画布里的 px），不依赖 OCC，也不遍历边线。

模板里的 x/y 先按容差聚成列和行，形成网格。列宽取同列视图的最大内容宽度，行高同理。统一缩放系数取「可用宽 / 列宽之和」与「可用高 / 行高之和」的较小者，可用区已经扣掉图框边距、标题栏占位和视图间距。算出系数后把网格整体居中排回图纸，视图内容左/上边界对齐到所属格子左上角。因此同列保持左右对齐、同行保持上下对齐，相对布局不变，但视图不会越框、间距不低于下限。

仅当统一缩放低于可读阈值时才考虑断裂，并且只切瓶颈方向：`front` / `back` 这类端视图的轴向垂直于投影面，`view_axes.axial_projection()` 返回 `None`，保持完整；轴测视图的 +Z 是斜投影，也不参与断裂。

## 断裂几何

`src/drawing/break_view.py` 是唯一变换源。断裂带落在内容轴向中部，避开端部特征：

```text
BreakSpec = {
  axis: 'x' | 'y',        # 画布局部轴向
  cutA, cutB,             # 断裂带起止，画布 px
  pxPerMm,                # bbox.scale
  waveAmp, waveCycles, visualGap
}
```

渲染不是删除边线，而是双段裁剪加右段平移：左段保留 `[0, cutA]`，右段保留 `[cutB, 画布边界]` 后整体左移 `cutB - cutA - visualGap`。两个切口之间留出一个视觉间隙，各画一条波浪线。

`edges` / `hidden_edges` 的长度、顺序和 `meta.mm_coords` 全部不动。标注以 `refs.idx` 强绑定边线数组下标，同系列型号的边线数量并不一致（实测 618 对 422），一旦删除或重排边线，整批标注会静默消失。断裂只新增 `view.break` 字段，并把所有坐标出口接到同一个投影函数：

- 后端 `dim_render._sheet_point()`、`drawing_source_render._edge_endpoints()`
- 前端 `useSheetCoords.getSheetPoint()`、`motorEnvelope.snapEndpointToViewEdge()`
- PDF 边线绘制 `dim_pdf_break.draw_broken()`

落在断裂带内的标注端点按到中点的距离贴到最近切口，所以尺寸线仍是一条连续线，只是跨度变短。Python 与前端 `cad-viewer-app/src/views/breakView.js` 用同一份 `tests/fixtures/break_view_cases.json` 对拍，字段和输出必须一致。

## 标注数值

数值真值优先取 `spanMm`、`meta.mm_coords`、`meta.radius` / `center_mm`，这些字段不受断裂影响。缺毫米元数据时，后端 `_fallback_mm()` 按标注方向在断裂轴上的分量把省略长度加回来，避免图上距离反算导致数值变短。电机包络的 `span_mm` 由目标型号锚点重算后写回 `spanMm`，不走几何反算。

`dim_rebind` 的端面吸附仍在未投影的画布坐标里做，和边线数组同源；投影在最后的坐标出口统一发生。上一轮加的 `SNAP_AXIS_MM = 3` 轴向容差保持不变，断裂不动 `mm_coords`，吸附逻辑天然不受影响。

## 三端一致性

`drawing_source.json` 的每个 view 在求解后写入 `x` / `y` / `scale` 和可选的 `break`，`edges` / `hidden_edges` / `contentBBox` 原样落盘。前端 `drawingDocument.js` 序列化、`loadDrawingDocument.js` 反序列化、`usePlacedViews.setViews()` 都透传 `break`，导入导出不丢配置。

前端工具栏「适应」和图纸规格切换走整组等比适配（`fitToSheet`），不再只改单个视图的比例；整组一起缩放时视图间距同步变化，断裂配置沿用求解结果，不做第二套实时求解。`applySpec.js` 只回填标题栏和参数表，不触碰 views 几何，因此无需透传 break。

顺带统一了两处既有口径：`drawing_source_render._view_scale()` 改用 `view.scale`（原来优先取 `bbox.scale`，把视图缩小近六倍），图框内边距统一为 20mm，并修正了把顶部坐标当矩形左下角导致图框跑出页面的问题。

## 已知边界

- 断裂由图纸空间触发，不是由行程长度直接触发。调色板把视图归一化到 400×300 画布，轴向视图宽度基本恒定：实测 L100→L180 在 A3 上统一比例从 0.93 调到 1.12（放大），不产生断裂；同一份数据在 A4 上无断裂比例只有 0.744，断裂后提升到 0.909。想让长行程在大幅面上也断裂，可以把 `DRAWING_MIN_READABLE_SCALE` 调高，但短行程会一起断裂。
- 前端编辑器里标注命中层仍按未投影的原始坐标画线。点击后标注引用的是边线下标，几何会按投影正确渲染；但断裂后的右段视觉位置和命中位置相差一个省略长度，在这段线上取点时可能不够跟手。
- 旧规则链路不产出 `view.break`，长行程若走这条链路仍可能越框。
- 标题栏占位目前按固定 55mm 从底部扣除，不解析实际 `tables` / `title_block` 的位置；标题栏很高时需要调大该配置。
