# 标注样式配置说明

`cad_viewer_style.json` 是前后端共用的标注样式真源。前端 `cad-viewer-app` 与后端 `src/drawing/dim` 读取同一份文件，改一处两端同步。

## 字段命名约定

- 后缀 `_px`：屏幕像素。前端 SVG 用 `non-scaling-stroke` 直接渲染；后端按 `_px_to_mm_at_96dpi` 折算成 mm。
- 后缀 `_mm`：图纸几何量，SVG viewBox 单位即 mm，前后端都不折算。
- `_px_to_mm_at_96dpi`：像素折 mm 系数（1px = 25.4mm / 96 ≈ 0.2645833mm）。只有 `_px` 类量经此折算，`_mm` 类几何量不经此折算。

## 配置项

### edge 模型边线

- `visible`：可见边线（实体轮廓线），`stroke_px` 线宽、`color` 颜色。
- `hidden`：隐藏边线（被实体遮挡的轮廓），用细灰线表示。

### dim 标注

- `line`：尺寸线，连接两端箭头的线。
- `ext`：延伸线，从被测边线引到尺寸线的引线。`overshoot_mm` 是延伸线越过尺寸线的长度，让线头略长出尺寸线、不与尺寸线齐平。
- `text`：标注文字。`gap_mm` 是文字与尺寸线之间的间距。
- `arrow`：尺寸线两端箭头（长尖实心三角）。`len_px` 为箭头沿尺寸线方向的长度；`half_px` 为箭头底部半宽，越小越尖锐；`extension_px` 是箭头向内（尖端相对、小尺寸放不下文字）时尺寸线穿过箭头向两侧延伸的长度，符合工程图尺寸线出头的习惯。

### center_mark 中心标记

十字线，标记孔/圆心位置，十字长度按孔半径自动取。

### frame / title_block 边框

- `frame`：图纸外框线。
- `title_block`：标题栏边框线。

### table 明细表

- `text.font_px`：单元格文字字号（px，沿用 96dpi 折算，与 `dim.text` 一致）。
- `border.stroke_mm`：表格线宽（mm）。
- `col_width_mm` / `row_height_mm`：列宽 / 行高（mm），绘制在 SVG viewBox 内，不经 `_px_to_mm_at_96dpi` 折算。
